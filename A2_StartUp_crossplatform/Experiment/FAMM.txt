--------------------------------------------------------------
EVERY FRAME  (before the 25 weights)
    1-3 first, then w. Engine already does this.
--------------------------------------------------------------

1. Get the two numbers
     X = A * theta + B * theta_dot     (pole)
     Y = C * x     + D * x_dot         (cart)

2. Compute the five memberships for X
     F_NL(X), F_NS(X), F_ZE(X), F_PS(X), F_PL(X)

3. Compute the five memberships for Y
     F_NL(Y), F_NS(Y), F_ZE(Y), F_PS(Y), F_PL(Y)

4. Then each of the 25 cells
     w = min( F_row(X), F_col(Y) )

   Then F = sum(w * c) / sum(w)   (c = Newton from the cell)


--------------------------------------------------------------
0. MEMBERSHIP FUNCTIONS  (lecture compact formulas)
    Same five formulas for Y: replace X with Y.
    Engine already does this in trapz(). Do not code these by hand.
--------------------------------------------------------------

NL  (left trapezoid)   a = -3, b = -1.5

  F_NL(X) = max( min( 1 , (b - X)/(b - a) ) , 0 )
          = max( min( 1 , (-1.5 - X)/1.5 ) , 0 )


PL  (right trapezoid)  a = 1.5, b = 3

  F_PL(X) = max( min( 1 , (X - a)/(b - a) ) , 0 )
          = max( min( 1 , (X - 1.5)/1.5 ) , 0 )


NS, ZE, PS  (regular / triangle)

  F(X) = max( min( (X - a)/(b - a) , 1 , (d - X)/(d - c) ) , 0 )

  NS  a=-3, b=c=-1.5, d=0
      F_NS(X) = max( min( (X + 3)/1.5 , 1 , (0 - X)/1.5 ) , 0 )

  ZE  a=-1.5, b=c=0, d=1.5
      F_ZE(X) = max( min( (X + 1.5)/1.5 , 1 , (1.5 - X)/1.5 ) , 0 )

  PS  a=0, b=c=1.5, d=3
      F_PS(X) = max( min( X/1.5 , 1 , (3 - X)/1.5 ) , 0 )
